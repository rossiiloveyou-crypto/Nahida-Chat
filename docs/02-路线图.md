# 02 · 路线图

## M0 · 可运行骨架 ✅ 已完成

**目标**：证明"环境能跑通、架构立得住"。

- [x] Electron 45 + Vite 7 + React 19 + TS 5.9 工程
- [x] 三进程分层（main / preload / renderer）+ 共享契约层
- [x] 单实例、导航白名单、窗口安全三项（contextIsolation / sandbox / nodeIntegration）
- [x] 奶油配色令牌化（`#FDFDE3`）+ 白色聊天窗口 + 白色输入框
- [x] 侧边栏左下角设置入口 + 设置页
- [x] 会话 CRUD、消息落盘、流式渲染、中断
- [x] 提示词目录 `Prompt/` + 设置页可选系统提示词
- [x] mock 适配器（离线）+ OpenAI 兼容适配器（SSE）
- [x] `pnpm typecheck` / `pnpm build` / `pnpm dev` 三绿灯，实机截图留档

**验收**：截图 `docs/preview/*.png` 来自真实运行，非设计稿。

## M1 · 对话内核（下一步）

**目标**：把"能聊"变成"聊得住"。

- [ ] 会话存储迁到 SQLite（better-sqlite3），消息分页加载
- [ ] 重新生成 / 编辑历史消息 / 从某条消息分支
- [ ] 会话重命名、置顶、搜索
- [ ] token 计数与上下文裁剪策略（超长时保留最近 N 轮 + 摘要）
- [ ] 失败重试与错误分类（网络 / 鉴权 / 限流 / 内容审核）

**DoD**：连续 1000 轮消息后启动不卡；断网重连后历史完整；`sessions.db` 可在线备份。

---

## M2 · 模型接入

**目标**：不止一个服务商，密钥不再裸奔。

- [ ] provider 抽象扩展：Anthropic / Gemini / Ollama（本地）
- [ ] apiKey 用 `safeStorage` 加密后落盘
- [ ] 代理与自定义 header 支持
- [ ] 模型列表拉取（`/models`）+ 连通性自检按钮
- [ ] 用量统计（token / 次数 / 成本估算）

**DoD**：切换三家的模型都能流式返回；配置文件里看不到明文 key。

---

## M2.5 · 长期记忆（RAG）✅ 已完成

**目标**：跨会话记住用户说过的事实，且全链路本地。

- [x] `node:sqlite` 记忆库 + FTS5 外部内容表
- [x] 本地 bge-m3（ONNX int8）embedding，懒加载、强制离线
- [x] 混合检索：向量 + 关键词融合（绝对余弦为主轴）
- [x] 对话后异步抽取记忆（**只从用户消息抽取**）
- [x] 注入点单次检索 + 用户可调的 token 预算（无硬上限）
- [x] 设置页「长期记忆」分区：开关、调参、列表、试召回
- [x] 30 项单测 + 15 项模型集成 + 9 项 Electron + 11 项端到端

**设计细节与实测数据**见 [04-RAG记忆检索设计.md](04-RAG记忆检索设计.md)。

## M3 · 提示词与工具

**目标**：从"聊天框"变成"可配置的助手"。

- [ ] 提示词热加载（`fs.watch`）+ `{{变量}}` 插值
- [ ] 角色卡 / 预设组合（系统提示词 + 参数）
- [ ] 工具调用（读文件、联网搜索）+ **权限模型**
- [ ] 提示词调试视图：看到最终拼给模型的完整 payload

**DoD**：工具调用必须有明确的用户授权，未授权一律拒绝，且能在日志里追溯。

> 这一里程碑的风险最高：一旦接了"能读本地文件"的工具，R2（提示词注入）就从理论问题变成真实问题。

## 里程碑依赖

```
M0 ──> M1 ──> M3 ──> M5
        └───> M2 ──┘
              └──> M4
```

M2 与 M3 可并行；M4 随时可插；**M5 必须等 M3 定型**，否则每次改资源路径都要重新打包验证。

## 开工前必须先回答的 3 件事

（详见 [00-审计报告.md](00-审计报告.md) 第 5 节）

1. 数据要不要出本机 → 决定 M1 的存储与同步设计
