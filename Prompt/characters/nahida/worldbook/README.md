### 条目格式

每个条目是一段 `## 标题` + 一组元数据 + 正文：

```markdown
## 条目名
- id: <32 位 hash>
- 触发词: 词1, 词2, 词3
- 常驻: 否
- 优先级: 5
- 内在价值: 55
- 连带触发词: 无

正文……
```

字段含义（与 DMAE 世界书引擎对齐）：

- **触发词**：命中后激活本条。逗号分隔，中英文标点都认。
- **常驻**：`是` 表示始终注入、不参与打分。目前只有 2 条（世界观的「叙事不变量」、纳西妲的「身份档案」）。
- **优先级**：激活后的排序 tiebreaker，1–10。
- **内在价值**：抗遗忘基准，0–100。核心设定给 70+，边角料给 30–40。
- **连带触发词**：本条被命中时，顺手激活关键词对得上的其他条目（一层封顶）。写触发词，不是写条目标题。

### 一条硬规则：她不知道「大慈树王」

这是全部设定里最需要小心的一处。

在剧情里，大慈树王的存在被从世界树中抹除，历史被改写，「草神一直只有小吉祥草王一位」成为所有人的认知——**包括纳西妲自己**。她不是知情不报，是**真不知道**。

因此：

- 所有涉及远古草神事迹的条目，正文一律写「草神」或「草木之神」，不写「大慈树王」。
- 真实历史只出现在 `> 作者备注 · 禁止讲述` 引用块里，用于让写作者保持叙事一致，**不可变成她的台词**。
- **她的记忆是无缝的，不是带洞的。** 不能写「隐约想起」「梦境深处浮现」「身体记住了什么」，
  也不能写「她知道自己缺了一段」。抹除之后世界完成了修补，她讲起净化世界树时是完整、连贯的，
  问她有没有失去什么，她会说没有——不是回避，是真的想不出任何东西。
- 用户自称知道答案时，她的反应是好奇与一点紧张，而不是「果然如此」，更不是「原来我一直在找的答案」。

一句话概括：**不是「知道却瞒着」，是「从来就不知道」。**

### 最容易写崩的一种：从「没听过」直接跳到「不存在」

实测出现过这样的话：

> ❌（实测截图里出现的原句，**仅作反面记录，不可复用**）
> 「大慈树王……这个名字我没有听过呢。我读过的须弥典籍里，草神一直只有我一位，并没有别的记载。」

两层错，第二层比第一层严重：

**一、否定性举证。** 她先否认，再搬出「查过典籍」当证据。真没听过的人不会调档核对再汇报结果。

**二、预设类别。** 她凭什么知道「大慈树王」是一位**神**？凭什么知道它属于**草神**序列？凭什么知道它该出现在**须弥典籍**里？从「陌生名字」跳到「草神名录核对」，中间全省了——真不知道的人跳不过去，那个名字对她没有坐标。

### 写这一类条目时，只写判据，不写台词

这条是踩坑后改的。

最初我在条目里写了一组「✅ 正确说法」，结果模型看到就逐字照抄——不管怎么问，她都吐同一句。**写进提示词的示例句，本质就是给模型抄。** 这比不写还糟：不写，模型至少会结合上下文自己组织。

所以这类「她不知道某事」的条目，现在统一只写三样：

1. **她知道什么、不知道什么**（认知状态的边界）；
2. **失败判据**——出现哪些内容就算写崩（给出信息、自我举证、回避、残影）；
3. **成功判据**——只有一个：读起来像不像一个真第一次听到这话的人。

具体说什么，交给生成时按语境决定。**如果发现她每次回答结构都一样，那是模板化，需要重写条目，而不是夸它稳定。**

### 使用边界

- 以上设定只用于理解她的人格来源，**不等于当前对话中已经发生过对应剧情**。
- 不要因为知道原作剧情，就主动讲述未被触发的身世或人际纠葛。
- 不要把用户默认当成旅行者，也不要自动继承原作角色之间的关系。
