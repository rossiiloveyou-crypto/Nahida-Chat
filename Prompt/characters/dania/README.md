# 妲妮娅 · 角色设定索引

> 这个文件是「妲妮娅」这个角色的入口，说明她的设定被拆到哪几个文件里。
> 改设定前先看这张表，只改对应文件，不要把所有内容堆回一个文件。

## 文件分工

| 文件 | 负责什么 | 什么时候改它 |
| --- | --- | --- |
| `soul.md` | 人格核心：她如何感受、判断、表达 | 想调整「她是个什么样的人」 |
| `canon/quotes.md` | 原作台词样本：她说过的原句，用来校准语感 | 想补台词 / 觉得她说话不像本人 |
| `worldbook/*.md` | 背景事实：地名、人物、事件、专有名词 | 想补充或修正设定知识 |
| `modes/chat.md` | Chat 模式的职责与事实边界（无工具） | 想改纯聊天时她该做什么、不该做什么 |
| `modes/agent.md` | Agent 模式的职责与权限边界（有工具） | 想改她干活时的权限、上下文与交付要求 |
| `styles/chat.md` | 日常对话的表达风格与节奏 | 想让闲聊更简短 / 更口语 |
| `styles/agent.md` | 带工具干活时的表达方式 | 想让她更像一个执行型助手 |

## 不在这个目录里的东西

- 全局底线规则（不针对任何角色）：`Prompt/shared/base.md`
- 全局语气与句式：`Prompt/shared/tone.md`
- Agent 的工具使用纪律（不针对任何角色）：`Prompt/shared/tool_usage.md`
- 台词填写模板与说明：`canon/_template.md`、`canon/README.md`（两者都不参与拼装）

> 工具清单本身由程序在请求里给出，不写在提示词里——写在这里会过期。

## 新增角色

在 `Prompt/characters/` 下新建一个目录，复制本文件的表结构，写好 `soul.md`、`modes/`、
`styles/` 与 `worldbook/`；要台词就把 `canon/_template.md` 复制成 `canon/quotes.md` 再填。
设置页不写死角色名，目录建好就会自动出现。
